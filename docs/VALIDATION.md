## 剩余限制

1. 首版单设备/单后端进程；内存状态不支持多 worker、多实例或 HA。重启清空帧和锁定意图，重连强制位置同步、录像未知。
2. 摄像头使用 OpenCV 本机驱动，原生采集调用故障可能阻塞该采集线程；没有实现专有 SDK 重连/曝光同步。源断开和过期画面应根据页面状态与年龄检查。
3. 上传相机会话没有独立心跳协议；无新帧时预览显示最后一帧及持续增长的年龄，不会继续分析旧帧。它不代表相机仍在线。
4. 只有可信位置查询/到位反馈才开放自动运动。桥接认证证明消息来自团队程序，不证明传感器一定正确；固件去重、过期、归位与运动中查询仍必须联调。
5. 历史图片/录像与当前真实镜片没有已验证关系时，仅展示分析。实时桥接的采集版本契约依赖适配器确实采集新画面；SDK 内部缓存仍需团队确认。
6. 录像默认未知，不自动检测。用户手动声明可能与现实不符，拍摄时应使用锁定；相机桥接报告超过心跳时限会重新设为未知。
7. 当前没有真实模型调用和语音识别。不能把模拟分析当识别准确率，也没有自动评价滤镜效果改善。
8. 事件/配置存于 SQLite；偏好与锁定是会话状态，重启不恢复。默认图片仅有界内存缓存。应用日志轮转，Docker 日志有限额；没有部署级日志平台或备份服务。
